## Описание проекта
«PetHome» — Сайт, который поможет людям найти кошку или собаку из приюта и подарить ей новый дом. На сайте можно будет посмотреть фотографии животных, почитать информацию о них, узнать об их возрасте и характере, а также оставить заявку, чтобы познакомиться с понравившимся питомцем. 

## Используемый фреймворк и способ подключения
- **Фреймворк:** Bootstrap 5.3 (подключён через CDN: `bootstrap.min.css` и `bootstrap.bundle.min.js`).
- **Кастомные стили:** файл `css/custom.css` подключён после Bootstrap для настройки CSS-переменных, БЭМ-компонентов и точного кадрирования фотографий.
